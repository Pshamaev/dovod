Здравствуйте. Это Довод

          

            Довод проходит дело по шагам и останавливается только там, где нужна
            ваша подпись.
          

          

            
            
          

          

            Учебное дело выдумано целиком. На нём можно нажимать всё без риска:
            ваши настоящие дела оно не затрагивает.
          

        

        

          
Открыть дело

          
Укажите папку, в которой лежат материалы дела.

          

            
          

          

            Имена и данные клиента остаются на вашем компьютере, наружу уходит
            только текст без них.
